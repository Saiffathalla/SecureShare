🔒 Security Layer
Encryption
AES-256-GCM at rest & in transit. Production: Web Crypto API + server-side key management.
AES-256Zero-knowledge
Authentication
JWT session tokens. 2FA via TOTP. Production: Supabase Auth or Auth0.
JWT2FA / TOTP
Access Control
Role-based (Admin / Manager / User). Time-limited share links with configurable expiry.
RBACExpiring links
Rate Limiting & Geo
API rate limiting toggle. Optional geo-blocking. Audit log for all events.
